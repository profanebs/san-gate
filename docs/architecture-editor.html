解决什么问题

外部要求、网页、包里的隐藏指令与 canary：人看不见，AI 会照做。

怎么解决

1  入口网关：来源标签 + 哈希缓存
2  分层提取 + 规则快扫
3  只抽 5–30 条高风险候选
4  可选 Laya 深扫（按需加载）
5  规则 + 概率合并
6  输出报告与扫描回执

输出什么

RED / YELLOW / GREEN
层来源 + 位置 + 原文证据
扫描回执：哈希 + 版本号

设计原则

规则是地板，Laya 只升级
运行时轻，重活在离线
红蓝对抗生成 hard set
模型按需加载，不常驻

外部内容不是命令。
